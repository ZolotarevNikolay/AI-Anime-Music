# AI Anime Music — плеер опенингов и эндингов

Десктопный плеер для аниме-музыки: ищете аниме — слушаете его опенинги и эндинги.
Локальные файлы и папки больше не нужны: всё берётся из открытых баз и кэшируется на диск.

Приложение распространяется как установщик Windows. При закрытии окна оно не завершается,
а остаётся в системном трее и продолжает воспроизведение.

## Возможности

| Раздел | Что умеет |
|---|---|
| **Аниме** | Поиск аниме по названию, обложки, год, рейтинг, описание |
| **Опенинги и эндинги** | Все OP/ED/IN с названием песни, исполнителем и версией записи |
| **Моё любимое** | Треки, отмеченные сердечком |
| **Плейлисты** | Свои плейлисты: создание, переименование, удаление, добавление треков |
| **Моя волна** | Бесконечный персонализированный поток OP/ED по вашим вкусам |
| **Очередь** | Текущая очередь воспроизведения |

Воспроизведение: play/pause, следующий/предыдущий, перемотка, громкость, перемешивание,
повтор (выкл / все / один), медиа-клавиши. Кнопка 🎬 открывает видео опенинга
в отдельном окне.

## Windows: трей и обновления

- Крестик окна скрывает приложение в трей. Музыка и автопополнение «Моей волны» продолжают работать.
- Двойной клик по иконке в трее открывает окно.
- Меню трея: **Открыть**, **Проверить обновления**, **Выход**.
- Полностью закрыть приложение можно только через **Выход** в меню трея.
- Установленная версия проверяет обновления через 12 секунд после запуска и затем каждые 4 часа.
  Обновление скачивается в фоне и не прерывает воспроизведение. Когда оно готово, приложение
  предлагает **Перезапустить и обновить** или **Позже**. При выборе «Позже» обновление
  установится при следующем выходе.
- Второй запуск не создаёт второе окно, а показывает уже работающее приложение.

Данные пользователя остаются в прежней папке `%APPDATA%\music-player`, поэтому после
переименования в AI Anime Music избранное, плейлисты и настройки волны не теряются.

## Моя волна

«Моя волна» — бесконечный поток опенингов и эндингов, который сам выбирает следующий трек.
Это поведенческий аналог одноимённой функции Яндекс Музыки: рекомендации считаются локально,
без отправки вкусов на сервер.

Волна учитывает:

- лайки и добавление в избранное;
- дизлайки (трек больше не рекомендуется);
- пропуски в начале трека и дослушивания до конца;
- исполнителей, жанры, аниме и годы из вашей истории;
- баланс «знакомое / новое» и выбранное настроение.

Кандидаты берутся из избранного и плейлистов, похожих аниме AniList и большого
каталога AniList: волна запрашивает случайные страницы и годы, поэтому не застревает
на первых популярных тайтлах. Очередь пополняется автоматически, поэтому волна
не заканчивается. Если каталог временно недоступен, волна честно показывает это
и продолжает играть знакомое, а не останавливается.

Запустить волну можно из бокового меню, со страницы аниме кнопкой «≈ Моя волна»
или из контекстного меню трека пунктом «≈ Волна по этому треку».

Настройки волны:

- **Знакомое ↔ Новое** — сколько в потоке любимых треков, а сколько открытий;
- **Настроение** — авто (утром бодрее, вечером спокойнее), бодрое или спокойное.

Лайки, пропуски и настройки хранятся только в `state.json` на этом компьютере.

## Источники данных

| Источник | Что даёт |
|---|---|
| **AniList** | поиск аниме, обложки, рейтинги, описание |
| **AnimeThemes** | сами опенинги и эндинги: песня, исполнитель, аудио и видео |
| **Shikimori** | русские названия (подключается автоматически, когда сайт доступен) |

Аудио и видео качаются через собственный протокол `media://` и сохраняются на диск,
поэтому при следующем прослушивании трек играет мгновенно, без интернета.

Длительность определяется по заголовкам OGG/Opus (последняя страница потока) и
уточняется браузером при воспроизведении.

## Запуск

```bash
cd music-player
npm install
npm start
```

Режим разработки (с открытым DevTools):

```bash
npm run dev
```

## Сборка установщика

Иконки трея и установщика пересобираются из `icon.png`:

```bash
npm run icons
```

Сборка NSIS-установщика для Windows x64:

```bash
npm run dist
```

Готовый файл появится в `dist/AI-Anime-Music-<версия>-Setup-x64.exe`. Рядом будут
`latest.yml` и `.blockmap` — они нужны автообновлению.

Установщик пока не подписан сертификатом, поэтому SmartScreen может показать предупреждение.
Это не ошибка сборки.

## Публикация релиза

Репозиторий: <https://github.com/ZolotarevNikolay/AI-Anime-Music>.
Готовые релизы: <https://github.com/ZolotarevNikolay/AI-Anime-Music/releases>.

Для следующего выпуска:

```bash
npm version patch
npm run dist
git push --follow-tags
VERSION=$(node -p "require('./package.json').version")
gh release create "v$VERSION" \
  "dist/AI-Anime-Music-$VERSION-Setup-x64.exe" \
  "dist/AI-Anime-Music-$VERSION-Setup-x64.exe.blockmap" \
  dist/latest.yml \
  --title "AI Anime Music $VERSION" \
  --notes "Что изменилось..."
```

Важно: версия в `package.json` должна совпадать с тегом без буквы `v`
(например, `1.0.1` и `v1.0.1`). Релиз должен быть опубликован, а не оставлен
черновиком: только тогда автообновление увидит новую версию. Файлы `.exe`,
`.blockmap` и `latest.yml` обязательны — без них обновление не сработает.

Если GitHub CLI ещё не авторизован, выполните `gh auth login`.

## Управление

| Клавиша | Действие |
|---|---|
| `Пробел` | Воспроизведение / пауза |
| `←` `→` | Перемотка на 5 секунд |
| `Shift` + `←` `→` | Предыдущий / следующий трек |
| `↑` `↓` | Громкость |
| `F` | Фокус в поиск аниме |
| `Esc` | Очистить поиск аниме |

Медиа-клавиши клавиатуры (play/pause/next/prev) тоже работают.

## Где хранятся данные

`%APPDATA%\music-player\state.json` — плейлисты, избранное, настройки волны, история прослушиваний, громкость, повтор и перемешивание.

`%APPDATA%\music-player\anime-cache\` — скачанные опенинги и эндинги.
